A microscopic view of your UI.

Lens is an intelligent browser plugin designed for developers and designers. Inspect computed styles, navigate DOM structures with your keyboard, and capture AI-ready annotations directly on your live website.

Test the Plugin Read the Docs

Localhost Comment Mode

When running on localhost, clicking an element instantly opens a comment popover. Draft prompts or feedback tied directly to specific DOM nodes.

Production Inspector Mode

Browse external websites and click any element to extract its layout, typography, colors, and spacing in a beautifully organized inspector UI.

Keyboard Navigation

Hold Alt (or Ctrl) and use your arrow keys and brackets to traverse the DOM tree with precision. Easily select parent, child, or sibling nodes.
